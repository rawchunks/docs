Rawchunks turns a brief into a song you can keep editing. Songwriter prepares the Studio form from text, an image or a recording. ACE-Step generates the audio and changes selected parts. Algorithmic Composer writes playable Code patterns around your project.

For creators, this means you can start with an idea instead of a completed arrangement. Musicians and producers can supply lyrics, musical controls and reference audio, then work with takes, stems and local instruments. Developers can use the same operations through the [API](/dev/overview).
