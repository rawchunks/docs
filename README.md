# Rawchunks docs

Documentation for the Rawchunks workstation, HTTP API, MCP server and on-chain contracts and programs.

[Read docs](https://docs.rawchunks.space) · [Launch app](https://app.rawchunks.space) · [Website](https://rawchunks.space)

## Sections

| Tab | Scope |
| --- | --- |
| App | Studio generation, multitrack editor, voices, covers, albums, instruments, live coding and Market. |
| Dev | Authentication, sessions, job polling, HTTP endpoints and `@rawchunks/mcp`. |
| Web3 | Base, Tempo and Solana contracts and programs for song registration, licensing and royalty splits. |

## Local preview

Install the [Mintlify CLI](https://www.npmjs.com/package/mint) and run from this repository:

```sh
npm i -g mint
mint dev
```

Preview at `http://localhost:3000`.
