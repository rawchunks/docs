Choose a positive interval in seconds that fits the source. This example changes seconds 15 through 30:

```javascript
const job = await api.post('/api/editing/apply', {
  songId, userAddress, task: 'repaint',
  repaintingStart: 15, repaintingEnd: 30,
  prompt: 'Sparse drums and a warmer bass',
  repaintMode: 'balanced', repaintStrength: 0.5,
  modelQuality: 'sft',
});
```

`conservative`, `balanced` and `aggressive` describe repaint intent. `repaintStrength` ranges from 0 to 1. You can request transition length through `repaintWavCrossfadeSec` and latent transition frames through `repaintLatentCrossfadeFrames`. Listen to the boundary; these are model controls, not guarantees of a precise audible crossfade.

For vocal changes, include `lyrics`. `/apply` also accepts seed, BPM, key and language. The shortcut `/repaint` uses `start` and `end` instead of `repaintingStart` and `repaintingEnd`.
