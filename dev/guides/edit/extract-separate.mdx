## Extract a time range

```javascript
const extracted = await api.post('/api/editing/slice', {
  songId, start: 15, end: 30,
});
const take = extracted.take;
```

The response is ready immediately with an inactive take. `start` and `end` are seconds on the selected source. Pass `stemId` to slice a particular stem. This does not bounce your live arrangement or effects.

The extracted file begins at its own time zero; its provenance records where it belongs on the song timeline. Use [candidate merge](/dev/guides/edit/merge) to place it correctly.

## Extract one instrument

Call [POST /api/editing/extract](/dev/endpoints/editing/extract) with `trackName` or `stemType`, such as `vocals` or `bass`. This uses Base-model extraction and returns a 202 job. Follow it with `task: "extract"`; optional source and region fields select the audio to process.

## Separate instruments

```javascript
const job = await api.post('/api/editing/isolate', {
  songId, userAddress, stemType: 'all',
});
```

Choose a stem ID from `/api/options`, such as `vocals`, `drums`, `bass`, `other` or `instrumental`. Even though submission returns HTTP 200, the body can say `pending` or `processing`.

On ready, use `result.stems`. Separation creates active takes for the returned tracks, with those stems initially muted. Reload the project. Your player can mute Master and unmute selected stems to audition them without doubling the same recording.

```javascript
await api.patch(`/api/editing/mixer/${encodeURIComponent(stem.id)}`, {
  is_muted: false,
});
```

`stem` is one returned stem selected by your user. Mixer persistence does not render a new audio file.
