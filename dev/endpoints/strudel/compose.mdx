## Graph summary

| Field | Type | Use |
| --- | --- | --- |
| `intent` | string | `compose` or `transform`. |
| `targetLayers` | string[] | `drums`, `bass`, `chords`, `arp`. |
| `mountedLibraries` | string[] | Library slices selected for this request. |
| `archetypeId / archetypeLabel` | string | Selected genre reference. |
| `refRole` | string | `drums`, `bass`, `vocals`, `keys`, `master`. |
| `sectionNode` | string | `intro`, `verse`, `build`, `drop`, `breakdown`. |
| `estimatedTokens` | integer | Character-based estimate of the prepared messages. |


## NDJSON events

| Field | Type | Use |
| --- | --- | --- |
| `graph` | event | Routing summary. |
| `status` | event | `step` describes current work. |
| `reasoning` | event | `text` explains the musical choices. |
| `code` | event | `code` updates the REPL. |
| `done` | event | Final `code` and optional `reasoning`. |
| `error` | event | `message` describes a failed run. |


## Use the result

[Integrate Composer](/dev/guides/edit/strudel). JSON is the default; consume streamed events by `type`. The `/strudel/` alias has the same contract.
