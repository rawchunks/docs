With neither `creator` nor `public=true`, the response is an empty array. There are no pagination parameters. Album visibility is a catalog setting, not a private storage boundary.

## Headers and parameters

<ParamField query="creator" type="string">
Creator address; takes precedence over public.
</ParamField>

<ParamField query="public" type="string">
Set the literal string true for public albums.
</ParamField>

## Response (200)

Success.
