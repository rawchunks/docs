Read the wallet pair and public profile for an address.

Use [request setup](/dev/guides/connect) for account headers.

## Path

<ParamField path="address" type="string" required>
Valid EVM or Solana address.
</ParamField>


## Response

Returns the account record with `evmAddress`, `svmAddress`, `nickname`, `avatar` and `bio`. Returns 404 when no pair exists.
