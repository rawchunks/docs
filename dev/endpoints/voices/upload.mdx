Send text fields before the file. An uploaded full mix is not automatically converted to isolated vocals. Saving and trained readiness are separate states.

[Voice upload and readiness](/dev/guides/generate/voices).

## Headers and parameters

<SessionHeader />

<ParamField header="x-session-user-address" type="string" required>
Selected account address. Required for owner-scoped reads and writes. It identifies the account; your product must authenticate its own users.
</ParamField>

<ParamField header="x-network-id" type="string">
Session network in CAIP-2 form, for example eip155:8453.
</ParamField>

## Multipart body

<ParamField body="creator" type="string" required>
Wallet address for the selected account. Use the same address as the session owner. Minimum length: `10`.
</ParamField>

<ParamField body="name" type="string" />

<ParamField body="file" type="file" required>
One WAV, MP3, FLAC, OGG, AAC, M4A/MP4 or WebM recording. Maximum 50 MiB. For preparation, use mono/stereo audio up to 240 seconds.
</ParamField>

## Response (202)

Accepted; follow the returned task.

Budget headers use six-decimal USDC atomic units. See [session payments](/dev/guides/payments#track-or-end-a-session).

## Errors

<Errors />

| Status | Meaning |
| --- | --- |
| `400` | Invalid request. |
| `401` | Invalid or expired session token. |
| `402` | Payment required or insufficient session budget. |
| `403` | Account does not match resource. |
| `404` | Resource not found. |
| `409` | Resource conflict; reload state or open an editable version. |
| `500` | Request failed. |

<RequestExample>

```bash cURL
curl --fail-with-body -X POST "$RAWCHUNKS_API/api/voices/upload" \
  -H "Authorization: Bearer $SESSION_TOKEN" \
  -H "x-network-id: $NETWORK" \
  -H "x-session-user-address: $USER_ADDRESS" \
  -F "creator=$USER_ADDRESS" \
  -F "name=Lead voice" \
  -F "file=@voice.wav;type=audio/wav"
```

</RequestExample>

</ResponseExample>
