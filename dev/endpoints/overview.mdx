The reference documents canonical music and project REST paths under `https://api.rawchunks.space`. Each page defines request fields, response fields and a copyable cURL call. Use [request setup](/dev/guides/connect) for account headers and the [payment guide](/dev/guides/payments) for paid calls.

For complete sequences, use the [Developer guides](/dev/overview). [Onchain calls](/dev/guides/publish/contract-reference) are separate from REST.

Use your own account, session token and returned resource IDs in the examples.

## Aliases

Use the canonical routes above in new integrations. The API also registers these equivalent shortcuts:

| Alias | Canonical route |
| --- | --- |
| `/generate`, `/status/{taskId}`, `/sample`, `/format` | Corresponding `/api/generation/*` route |
| `/repaint`, `/layer`, `/extend`, `/remix`, `/separate` | Corresponding `/api/editing/*` route |
| `/songs` | `GET /api/songs` |
| `/voices` and its subpaths | `/api/voices` and matching subpaths |
| `POST /voice` | `POST /api/voices` |
| `POST /api/editing/commit` | `POST /api/editing/commits` |
| `POST /api/editing/takes/activate` | `POST /api/editing/activate` |

The API's `/docs` route serves Swagger UI. The namespaced endpoints above are the integration reference. There are no public cancellation, manual-training, webhook registration or server DAW-control routes.
