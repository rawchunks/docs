Without `creator`, only public songs are returned, newest first. A creator query includes that owner’s private songs and requires their account header. No default page cap is applied; send `limit` and `offset`. There is no total-count or cursor field.

[Paginate and manage a library](/dev/guides/library).

## Headers and parameters

<ParamField query="creator" type="string">
Owner library. Requires x-session-user-address with the same address.
</ParamField>

<ParamField query="limit" type="integer">
Positive integer page size. Minimum: `1`.
</ParamField>

<ParamField query="offset" type="integer">
Nonnegative integer offset. Minimum: `0`.
</ParamField>

## Response (200)
