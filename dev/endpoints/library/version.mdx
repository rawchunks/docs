import Errors from '/snippets/dev/errors.mdx';
import SongFields from '/snippets/dev/models/song.mdx';

An unminted song returns itself. A minted song returns a private draft with copied arrangement and cleared mint fields. An existing draft for the same basis can be reused. Always continue with the returned `id`.

## Headers and parameters

<ParamField path="id" type="string" required>
Resource ID.
</ParamField>

<ParamField header="x-session-user-address" type="string" required>
Selected account address. Required for owner-scoped reads and writes. It identifies the account; your product must authenticate its own users.
</ParamField>

## Response (201)

Success.

<SongFields />

## Errors

<Errors />

| Status | Meaning |
| --- | --- |
| `400` | Invalid request. |
| `403` | Account does not match resource. |
| `404` | Resource not found. |
| `409` | Resource conflict; reload state or open an editable version. |
| `500` | Request failed. |

<RequestExample>

```bash cURL
curl --fail-with-body -X POST "$RAWCHUNKS_API/api/songs/$(jq -nr --arg v "$ID" '$v|@uri')/version" \
  -H "x-session-user-address: $USER_ADDRESS"
```

</RequestExample>
