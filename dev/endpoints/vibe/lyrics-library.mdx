Read the supported lyric tags and lyric-writing reference.

Use [request setup](/dev/guides/connect) for account headers.

## Response

<ResponseField name="tags" type="object">
Arrays grouped by `structure`, `intensity`, `solo`, `vocal`. Each tag has `token`, `category`, `description`.
</ResponseField>

<ResponseField name="systemPrompt" type="string">
Lyric-writing reference.
</ResponseField>
