Poll by the task/song/user binding. A ready candidate has `take` and `audioUrl`; ready separation has `stems`. There is no edit event stream.

[Follow jobs](/dev/guides/jobs).

## Headers and parameters

<ParamField path="taskId" type="string" required>
Resource ID.
</ParamField>

<ParamField query="songId" type="string" required>
Same song as submission.
</ParamField>

<ParamField query="userAddress" type="string" required>
Same selected account as submission.
</ParamField>

<ParamField query="task" type="string" required>
Task kind returned by submission. Values: `repaint`, `lego`, `complete`, `extend`, `cover`, `extract`.
</ParamField>

<ParamField query="stemId" type="string">
Same target stem if supplied.
</ParamField>

<ParamField query="prompt" type="string">
Optional original prompt.
</ParamField>

<ParamField query="repaintingStart" type="string">
Optional original start, decimal seconds.
</ParamField>

<ParamField query="repaintingEnd" type="string">
Optional original end, decimal seconds.
</ParamField>

<ParamField header="x-session-user-address" type="string" required>
Selected account address. Required for owner-scoped reads and writes. It identifies the account; your product must authenticate its own users.
</ParamField>

## Response (200)

Success.
