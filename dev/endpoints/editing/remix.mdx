This changes audio style. It does not create a licensed remix relationship. For seed, tempo, key or language controls, use `/apply` with `task: "cover"`.

Poll with the returned task kind `cover`. Completed edits remain pending until [activation or merge](/dev/guides/edit/takes).

## Headers and parameters

<SessionHeader />

<ParamField header="x-session-user-address" type="string" required>
Selected account address. Required for owner-scoped reads and writes. It identifies the account; your product must authenticate its own users.
</ParamField>

<ParamField header="x-network-id" type="string">
Session network in CAIP-2 form, for example eip155:8453.
</ParamField>

<RequestExample>

```bash cURL
curl --fail-with-body -X POST "$RAWCHUNKS_API/api/editing/remix" \
  -H "Authorization: Bearer $SESSION_TOKEN" \
  -H "x-network-id: $NETWORK" \
  -H "x-session-user-address: $USER_ADDRESS" \
  -H "Content-Type: application/json" \
  --data "$(jq -nc --arg user "$USER_ADDRESS" --arg song "$SONG_ID" '{
  "songId": $song,
  "userAddress": $user,
  "prompt": "Dusty hip-hop drums and muted piano",
  "coverStrength": 0.65
}')"
```

</RequestExample>
