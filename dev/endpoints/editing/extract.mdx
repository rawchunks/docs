Send `trackName` or `stemType` for Base-model instrument extraction. Omit both to slice an interval. Use [the dedicated slice route](/dev/endpoints/editing/slice) when you only need a section.

<SessionHeader />

## JSON body

<EditSource />

| Field | Type | Use |
| --- | --- | --- |
| `trackName` | string | Instrument to extract. |
| `stemType` | string | Alternative instrument target. `trackName` takes precedence. |
| `prompt` | string | Extraction direction. |
| `lyrics` | string | Vocal text. |
| `globalCaption` | string | Overall musical context. |
| `start`, `end` | number | Nonnegative region bounds in seconds. Required for slicing; end must exceed start. |
| `repaintingStart`, `repaintingEnd` | number | Extraction bounds; take precedence over start/end. |

Instrument extraction selects Base. The slicing path uses `songId`, source fields and start/end bounds.

## Response

Instrument extraction returns HTTP 202 with `taskId`, `songId`, `status`, optional `stemId` and `task: "extract"`. Follow [edit status](/dev/endpoints/editing/status) or [events](/dev/endpoints/editing/events).

Slicing returns HTTP 201 with `{ success, take }`. Its audio is at `take.url`. The new section take starts inactive.
