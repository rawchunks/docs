Open a completed track with **EDIT** in Studio, or **MY-PAGE → MY SONGS → ••• → AUDIO EDITOR**. Editing a minted version creates a new editable version.

## Find your way around

The top transport plays the arrangement. Below it, the large waveform shows the selected lane. The small **MST** waveform returns focus to Master.

The stem matrix holds your other lanes and takes. Select a square to focus it; use its play icon to hear it alone. **+N** opens the remaining tracks and takes. **Master** holds the song's main audio.

The manual toolbox sits beside the matrix. Its bottom dock shows recent tools and shortcuts. Open **+N** for the others: **FX**, **MIXER**, **KEYS**, **DRUMS**, **CODE**, **SAMPLE**, and **HISTORY**.

**AI Studio** runs along the bottom. Select an operation, enter your prompt, and open its summary button for settings. The target badge shows the lane and selected range.

## Select and listen

Drag horizontally over an audio waveform to select a range. Adjust the start and end handles, or drag the move handle to reposition it. The selection's controls offer **AUDITION**, **EXTRACT**, **REWORK**, and **×** to clear it. On a phone, use **SECTION** to open a range selector.

</Frame>

| Control | What it does |
| --- | --- |
| **PLAY / PAUSE** | Play or pause the arrangement |
| Stop square | Stop and return to the beginning |
| Return-to-zero icon | Seek to the beginning |
| Loop icon | Repeat the selection, or the whole song when no range is selected |
| **AUDITION** | Play the selected section |
| Lane play icon | Hear that lane alone |
| **M / S** | Mute or solo a lane |

Outside text fields, **Space** plays or pauses, **Shift+Space** auditions a selection, **L** toggles looping, and **Home** or **0** returns to the start. Select the header's **BPM** badge to set the project tempo for your patterns.

## Choose a tool

| Work | Guide |
| --- | --- |
| Change a section | [Rework](/app/rework) |
| Pull out audio or stems | [Extract and separate](/app/extract-separate) |
| Add a part or backing arrangement | [Layer](/app/layer), [Accompany](/app/accompany) |
| Continue or change the style | [Extend and Restyle](/app/extend-restyle) |
| Keep an edit | [Takes and merging](/app/takes-merge) |
| Write your own parts | [Keys](/app/keys), [Drums](/app/drums), [Code](/app/live-code), [Sampler](/app/samples) |
| Shape and balance audio | [Wave sculpting](/app/wave-sculpting), [Mixer and effects](/app/mixer-effects) |
| Return to saved work | [History](/app/history) |

The document icon on the waveform opens the [song's lyrics](/app/lyrics#lyrics-in-the-editor). **Undo**, **Redo**, and **COMMIT** sit beside it.
