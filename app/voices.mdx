Open **STUDIO → CONTROL → MORE OPTIONS → VOICE**. Choose **UPLOAD** for a reference file or **SAVED** for a prepared voice.

## Use a vocal reference

1. In **UPLOAD**, select or drop an audio file. Supported formats are WAV, MP3, FLAC, OGG, and WebM.
2. Review the selected file. Replace or clear it if needed.
3. Set **RESEMBLANCE**, then **DONE**.
4. Select **GENERATE AUDIO**. The app saves the sample at that point and uses it as a vocal reference.

For trained reuse, choose an isolated mono or stereo vocal recording of no more than **four minutes**. Uploads can be up to **250 MiB**. A longer recording can save and still fail preparation.

Selecting a local file does not upload it. A new upload has its own [service charge](/app/payments#service-prices), separate from generation.

## Save a song's voice

On a **READY** Studio variation, select **SAVE VOICE**. Rawchunks saves its vocals as a voice profile and prepares them for reuse. Find it in **MY-PAGE → MY VOICES** or the **SAVED** selector.

## Reuse a prepared voice

Choose **FAST** or **MASTER** in Studio first. Open **VOICE → SAVED**, select an enabled voice, then **DONE**. A voice that is not ready for the selected mode stays disabled.

<Frame caption="Example project in the current Rawchunks app.">
  <img src="/images/app/voice-saved.jpg" alt="Saved voice selected in the current Voice dialog with resemblance slider and Clear, Cancel, and Done." />
</Frame>

Preparation creates a small trained voice adaptation, called **LoRA**, for each generation mode. Saving the voice starts this preparation.

## Set resemblance

**RESEMBLANCE** covers **10–100%**, starting at **65%**. Higher values request a closer match to the voice. Listen to the result before using it as a finished vocal.

**CLEAR** removes the voice from your generation settings. **RETRY** after a loading error refreshes the list; it does not restart training.
