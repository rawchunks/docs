title: "Write a Keys pattern"
sidebarTitle: "Keys"
description: "Play and record notes in a repeating two-bar piano roll."
---

Open **KEYS** in the manual dock or **+N** menu. Create a Keys track if prompted, then select **OPEN KEYS EDITOR**. The waveform's add menu also creates a Keys lane.

<Frame caption="Example project in the current Rawchunks app.">
  <img src="/images/app/editor-keys.jpg" alt="Expanded Keys editor with two-bar piano roll, computer-keyboard notes, note division, velocity, version selector, and recording control." />
</Frame>

1. Choose **1/4**, **1/8**, **1/16**, or **1/32** for new note lengths, and a **VEL** value for their velocity.
2. Select a pitch/time cell to add a note. Select an existing note to remove it.
3. Play the pitch labels or use the laptop keys printed beside them. **Z/X** change octave; **C/V** change velocity.
4. Enable **KEY** step recording to enter notes with your keyboard. Each recorded note advances the cursor. The left/right arrows move that cursor.
5. Use **QUANTIZE** to align notes to the chosen grid, or the clear icon to empty the pattern.
6. Play the arrangement to hear the two-bar part repeat. Set its tempo with the header's **BPM** badge.

The compact preview gives you quick access to the pattern. Numbered pills switch versions; **+** creates a fresh version on the same lane. Balance it with [Mixer and effects](/app/mixer-effects).
