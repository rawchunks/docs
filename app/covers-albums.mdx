Both controls are in **STUDIO → CONTROL → DETAILS**, above the prompt.

See the [Studio Details screenshot](/app/generate) for the album picker and cover controls.

## Add a cover

Select **UPLOAD COVER** to choose an image. Select an existing cover to view it larger. Use its small **×** to clear it, then upload a replacement.

To request artwork, enter a prompt, lyrics, or title and select the sparkle button, **Generate Cover with AI**. It uses your song brief, title, and style tags. The sparkle button on an existing cover requests new artwork.

[Vibe](/app/vibe) prepares cover art with the song draft. Review it here, or upload your own. Wait for artwork preparation to finish before generating audio.

The selected cover is attached to the track when you generate it.

## Choose or create an album

1. Open **ALBUM** and select an existing album.
2. For a new one, choose **+ NEW ALBUM…**, enter a title, then **CREATE**.
3. Generate the track with that album selected.
4. Select the same album for other new tracks you want to group with it.

You can see album cards under **MY-PAGE → MY ALBUMS**. They show the title, cover if present, listing status, and date.
