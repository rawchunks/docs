Open **CODE** in the manual dock or **+N** menu, then **OPEN CODE REPL**. Create a Code track if prompted.

Choose **4/4 TECHNO**, **BREAKBEAT**, or **ACID BASS** as a starter, or enter your own pattern. A simple beat is:

```javascript
s("bd sd hh cp")
```

Select **RUN** or press **Shift+Enter** in the editor to evaluate it and sync playback to the project tempo. The stop and clear icons control playback and the current text.

## Ask for a pattern

Enter a musical request in the **AI Live-Code prompt**, such as “A muted bass pulse and a sparse offbeat hi-hat,” then **AI CODE**. The request uses the current song's musical context. Read and run the returned pattern, then listen before keeping it.

## Change the sound

**SPEED**, **LPF CUTOFF**, **REVERB**, and **DELAY** provide quick adjustments. Numbered pills switch Code versions; **+** creates another version.

The editor supports sound and note patterns, rests, subdivisions, repetition, and timing modifiers. Keep patterns small while testing them. Arbitrary JavaScript and every Strudel feature are not supported here.
