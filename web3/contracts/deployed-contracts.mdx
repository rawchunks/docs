## Check your connection

```bash
export RPC_URL=https://sepolia-rollup.arbitrum.io/rpc
cast chain-id --rpc-url "$RPC_URL"
cast code 0x4Ac838b970D44AB9056b4201e9ED3c1Ce271545e --rpc-url "$RPC_URL"
cast call 0xC5c7d2645A7119b538C8d752Ce61c9706cDF7A36 'factory()(address)' --rpc-url "$RPC_URL"
cast call 0xff402e0C8c9a19f855200524260A858DDF99EdcD 'usdc()(address)' --rpc-url "$RPC_URL"
```

These are read-only calls. Expect chain ID `421614`, nonempty Factory code, and the Factory and token addresses listed above. Repeat the checks for your selected network before requesting a wallet transaction.
