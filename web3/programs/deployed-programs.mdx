## Check program availability

Install `@solana/kit`. Use the RPC and IDs from [Programs stack](/web3/programs/stack#connect-your-project):

```javascript
const genesis = await rpc.getGenesisHash().send();
if (genesis !== 'EtWTRABZaYq6iMfeYKouRu166VU2xqa1wcaWoxPkrZBG') {
  throw new Error('Expected Solana devnet');
}
for (const id of [factoryProgram, remixProgram, royaltiesProgram]) {
  const { value } = await rpc.getAccountInfo(id, {
    encoding: 'base64', commitment: 'confirmed',
  }).send();
  if (!value?.executable) throw new Error(`Program unavailable: ${id}`);
}
```

Executable-account checks establish that a program is present. Check its config and required operation permissions too. Use [the account reference](/web3/programs/accounts) to decode config and song state.
