

<ParamField body="songId" type="string" required>
Opaque ID returned by the API. Minimum length: `1`.
</ParamField>

<ParamField body="stemId" type="string">
Optional target stem in this song. Omit to use the master.
</ParamField>

<ParamField body="userAddress" type="string" required>
Wallet address for the selected account. Use the same address as the session owner. Minimum length: `10`.
</ParamField>

<ParamField body="srcAudioUrl" type="string">
Optional source override, for example the url from Upload source. Use an HTTP(S) URL.
</ParamField>

<ParamField body="modelQuality" type="string">
Select a mode listed for this task by GET /api/options. Defaults to base. Layer and Accompany require base. Values: `turbo`, `sft`, `base`.
</ParamField>

<ParamField body="modelVariant" type="string">
Alternative to modelQuality. If both are sent they must match. Values: `turbo`, `sft`, `base`.
</ParamField>

<ParamField body="seed" type="integer">
Optional seed. Omit for a random seed; this is not a guarantee of byte-identical audio. Range: `0` to `9007199254740991`.
</ParamField>

<ParamField body="bpm" type="number">
Tempo in beats per minute. Range: `30` to `300`.
</ParamField>

<ParamField body="keyScale" type="string">
Key ID from GET /api/options.
</ParamField>

<ParamField body="vocalLanguage" type="string">
Language ID from GET /api/options.
</ParamField>

<ParamField body="audioDuration" type="number" required>
Target total length, not seconds to add. Must exceed source duration. Minimum: `5`.
</ParamField>

Minimum: `0`.
